# Contributing

Keep changes small and reproducible. Include the source URL, exact observation
time, reference date, test command and actual result. Distinguish synthetic
fixtures from observed records. Do not post registry contacts, credentials,
private paths, patient records, private chat captures or internal ORION data.

Report a correction by NCT ID and affected field, with source evidence. Preserve
the old dated release; do not silently rewrite it. New observations need a new
dated directory. Missing fields remain UNAVAILABLE. No scores, rankings,
recommendations, price targets, forecasts or inferred company misconduct belong
in this tool's output.

Run the package tests and the publication audit before proposing a release.
Maintainers review changes before merging. There is no auto-publish workflow.
Do not add automatic outreach, mail, secrets, paid APIs or a persistent collector.

This repository is not the external Time Capsule submission portal. That future
process needs its own approved protocol and observed timestamping infrastructure.
